# GitHub profile setup

1. Create a **public** repository named exactly `financesoulbyshiva`.
2. Add the included `README.md` at the repository root.
3. Upload `assets/profile-banner.svg` to the repository if you want to use the banner. To show it at the top, add this line immediately after `<div align="center">` in README:
   `\n<img src="assets/profile-banner.svg" alt="Shivprasad Gopawar — Software Engineering, AI and Cybersecurity" width="100%" />\n`
4. In GitHub, open **Your profile → Edit profile** and update your bio, location (optional), website, and social links.
5. Pin 4–6 strongest repositories from your profile. Suggested order: NEXUS-OSINT, Saheli, CareerPath AI, ProjectPulse, LUCOUS.
6. Replace the LinkedIn placeholder with your real public profile URL. Add a portfolio URL only when it is live.
7. Review the project descriptions and technology badges against each repository before publishing.

## Important notes
- GitHub profile README appears when a public repository has the exact same name as your username and contains a root `README.md`.
- GitHub stats cards are third-party dynamic images and may occasionally be unavailable or rate-limited. The profile remains readable without them.
- The banner is an SVG source file and can be edited as text or in a vector editor.
